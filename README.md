# Phoobobo’s Herdr Mods

Mods for Herdr App. Each folder contains the mod files, a recipe, and a preview.

- [Files Markdown](files-markdown/) — read Markdown in the Files panel with a Preview/Source toggle.
- [Provider Token Status](provider-token-status/) — show weekly provider quota in the status bar.

To add a mod, copy its `mods/<name>/` into your Herdr App home and follow its `RECIPE.md`. Review the documented commands and file access before installing.
